// Vapi Server URL Settings Server URL: https://tryvela.io/webhook/{{ agent.id }} Events to send: end-of-call-report // Vapi sends this automatically after each call // Vela will receive and log it instantly
In Make (formerly Integromat), add an HTTP → Make a request module:
// Make HTTP Module Settings URL: https://tryvela.io/webhook/{{ agent.id }} Method: POST Body type: Raw Content type: application/json Body: { "event_type": "conversation", "summary": "{{1.summary}}", "outcome": "success" }
Test your webhook connection directly from terminal:
